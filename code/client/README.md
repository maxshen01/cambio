# Cambio client

React/Vite client for joining the shared Cambio room and displaying recipient-authorized game state.

Start the [server](../server/README.md) first. From this directory:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the URL Vite prints, normally `http://localhost:5173`.

See [Development](../Development.md) for setup, diagnostics, [focused/file/name/watch commands](../Development.md#client-commands), and the [pre-merge gate](../Development.md#pre-merge-gate). Specifications: [UI Rules](../../project-managment/designs/UI%20Rules.md), [Events Contract](../../project-managment/Events%20Contract.md), and [Game Rules](../../project-managment/Game%20Rules.md). [Test Scenarios](../../project-managment/Test%20Scenarios.md) defines acceptance and manual validation.
